Plan: free

Frontend framework: React + Vite
Backend: Express API server in server/server.js
Database/storage: file-based JSON in server/data/db.json

Main features:
- Embed generator for YouTube, Shorts, TikTok, Instagram, and generic URLs
- Signup and login with email OTP verification
- Custom OTP email branding with logo and support links
- Dashboard to review saved embeds and subscription status
- Maintenance mode support via environment variables
- Render deployment configuration in render.yaml

Important files:
- src/App.jsx: main React UI and auth flow
- src/App.css: app styling and maintenance UI
- server/server.js: API endpoints, OTP, email sending, auth/session handling
- render.yaml: Render deployment config and env var defaults
- README.md: setup, scripts, deployment notes

NPM scripts:
- npm run dev: start Vite frontend
- npm run server: start Express backend
- npm run dev:full: run frontend and backend together
- npm run build: build production frontend assets
- npm start: run the production server

Render environment variables used:
- SITE_URL=https://mo7mels.com
- SITE_NAME=Mo7mels
- SITE_LOGO_URL=https://mo7mels.onrender.com/site-logo.svg
- ENABLE_CANONICAL_REDIRECT=true
- VITE_MAINTENANCE_MODE=false
- VITE_MAINTENANCE_TITLE="نعتذر لإزعاجك"
- VITE_MAINTENANCE_MESSAGE="الموقع حالياً يخضع لرفع تحديثات. سنعود قريباً بخدمة أفضل. شكراً لصبرك."
- VITE_LINKEDIN_URL=https://www.linkedin.com/company/mo7mels
- SMTP_HOST, SMTP_PORT, SMTP_SECURE, SMTP_USER, SMTP_PASS, EMAIL_FROM (sensitive credentials)
